# Database Schema

PostgreSQL. In dev, Hibernate (`ddl-auto: update`) creates/updates these tables from the entities.
In prod (`ddl-auto: validate`) they must already exist — the DDL below is the source of truth.

Every table is scoped per user by a `uuid user_id`. The application filters every query by it; if
your Postgres also enforces Row Level Security, that is an additional layer.

---

## DDL (prod)

```sql
CREATE TABLE IF NOT EXISTS public.calls (
    id                      bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id                 uuid NOT NULL,
    technician_name         text,
    title                   text,
    transcript              text NOT NULL,
    knowledge_base          text,
    report_extracted_data   jsonb,
    atendio                 text,
    numero_cuenta           text,
    direccion               text,
    protocolo_kb            text,
    severidad               varchar(20),
    responsabilidad         varchar(30),
    sintoma_reportado       text,
    diagnostico             text,
    acciones_recomendadas   jsonb,
    estado_resolucion       varchar(40),
    orden_trabajo           text,
    tiempo_respuesta        text,
    cumplimiento_protocolo  text,
    sentimiento_cliente     varchar(20),
    report_summary          text,
    report_generated_at     timestamptz,
    created_at              timestamptz,
    updated_at              timestamptz
);
CREATE INDEX IF NOT EXISTS idx_calls_user_created ON public.calls (user_id, created_at DESC);

CREATE TABLE IF NOT EXISTS public.knowledge_bases (
    id          bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id     uuid NOT NULL UNIQUE,
    content     text NOT NULL,
    created_at  timestamptz,
    updated_at  timestamptz
);

CREATE TABLE IF NOT EXISTS public.prompt_templates (
    id          bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id     uuid NOT NULL UNIQUE,
    content     text NOT NULL,
    created_at  timestamptz,
    updated_at  timestamptz
);

CREATE TABLE IF NOT EXISTS public.technician_profiles (
    id            bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id       uuid NOT NULL UNIQUE,
    display_name  text NOT NULL,
    created_at    timestamptz,
    updated_at    timestamptz
);
```
